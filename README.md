## 🚀 How to View the Website

You can view the website immediately in any web browser without needing any server or build step:

### Option 1: Direct File Open
Double-click `index.html` in file explorer or open it in your browser:
```text
C:\Users\HP\.gemini\antigravity-ide\scratch\nirav-institute\index.html
```

### Option 2: Local HTTP Server (Python)
Run the following in PowerShell:
```powershell
cd C:\Users\HP\.gemini\antigravity-ide\scratch\nirav-institute
python -m http.server 8080
```
Then visit: `http://localhost:8080` in Chrome, Edge, or Firefox.
